```

- **Requisito afectado**: [id o descripción]
- **Pasos para reproducir**: 
- **Comportamiento esperado**: 
- **Comportamiento actual**: 
- **Archivo afectado**: 
- **Estado**: ABIERTO | EN CURSO | CERRADO
```
