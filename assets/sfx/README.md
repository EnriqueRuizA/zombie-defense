# Efectos de sonido (opcional)

Si añades aquí archivos `.wav`, el juego los usará:

- **click.wav** — clic en menú (New Game, Load, Quit)
- **build.wav** — al construir (HQ, Almacén, Torre)
- **save.wav** — al guardar partida
- **day.wav** — al cambiar de día

Si no existen, no se reproduce nada (sin errores).
